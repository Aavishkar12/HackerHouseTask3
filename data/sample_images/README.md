# Sample images

Put your test photo here as `me.jpg` (or pass any path as an argument to
`scripts/demo_encode.py`).

Guidelines for a good test photo:
- One person, front-facing, reasonably well lit.
- JPEG or PNG, not tiny/heavily compressed.

This folder's contents (other than this file) are git-ignored, since a
personal photo shouldn't be committed to the repo.
